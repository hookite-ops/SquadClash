SQUAD CLASH (스쿼드 클래시) — Google Cloud Run 배포 방법
=====================================================

준비물: 결제 계정이 연결된 Google Cloud 프로젝트 1개

1) https://console.cloud.google.com 접속 → 오른쪽 위 [>_] 아이콘(Cloud Shell) 실행
2) Cloud Shell 오른쪽 위 ⋮ 메뉴 → [업로드] → squad-clash.zip 선택
3) 아래 한 줄을 붙여넣고 실행

   unzip -o squad-clash.zip && bash squad-clash/deploy.sh

   ※ 예전 파일이 남아 있으면 옛 버전이 올라갑니다. 다시 올릴 때는 업로드 전에 먼저:
      rm -rf ~/squad-clash ~/squad-clash*.zip

4) 3~5분 뒤 마지막 줄에 나오는 https://squadclash-....run.app 주소가 게임 주소입니다.
   친구에게 그 주소를 보내고, 같은 "방 코드"를 입력하면 같은 방에서 만납니다.
   ("빠른 참가"는 공개방으로 들어갑니다.)

※ 'storage.objects.get denied' 403 오류는 새 프로젝트에서 빌드 권한이 없어 생기는 것으로,
   deploy.sh가 자동으로 권한을 넣고 다시 시도합니다.

다시 올릴 때(수정 후)도 2~3번만 반복하면 됩니다.

GitHub 자동 배포 (한 번만 설정하면, 저장소 main 에 올라올 때마다 저절로 새 버전이 배포됩니다)
- 저장소: https://github.com/hookite-ops/SquadClash
- 설정 (Google Cloud 콘솔에서 한 번):
  (지금은 서울 서비스 squadclash 가 이 저장소에 연결되어 있습니다: https://squadclash-394173969859.asia-northeast3.run.app)
  1) console.cloud.google.com → Cloud Run → 서비스 목록 위쪽 [저장소 연결] (서비스 이름 squadclash, 리전 asia-northeast3)
  2) 저장소 제공업체 GitHub → 인증 → Google Cloud Build 앱을 hookite-ops/SquadClash 에 설치 → 저장소 선택 → [다음]
  3) 브랜치 ^main$ · 빌드 유형 Dockerfile · 소스 위치 /Dockerfile → [저장]
- 그 뒤로는 main 에 올라올 때마다 3~5분 안에 같은 주소로 새 버전이 뜹니다. 위의 zip 업로드는 하지 않아도 됩니다.
- 꼭 맞춰야 하는 설정: 최대 인스턴스 1 (2 이상이면 같은 방 코드로도 서로 못 만남). Cloud Shell 에서 한 번:
    gcloud run services update squadclash --region asia-northeast3 --max-instances 1 --min-instances 0 --concurrency 250 --timeout 3600 --session-affinity --port 8080

알아둘 점
- 아무도 접속하지 않으면 서버가 자동으로 꺼져서 요금이 거의 나오지 않습니다.
  (첫 접속 때 켜지느라 몇 초 걸릴 수 있어요.)
- 모든 방이 서버 1대 안에서 돌아가도록 max-instances=1 로 고정했습니다. 이 값은 바꾸지 마세요.
- Cloud Run은 연결 하나를 최대 60분까지 유지합니다. 끊기면 게임이 자동으로 다시 접속합니다.
- 리전을 바꾸려면:  REGION=asia-northeast1 bash squad-clash/deploy.sh

내 컴퓨터에서 먼저 돌려보기:  npm install && npm start  →  http://localhost:8080

게임 모드
- 폭탄전(라운드): 공격팀은 A/B 지점에 폭탄 설치, 수비팀은 해체하거나 막기. 5라운드 선취, 4라운드 뒤 공수 교대.
  킬·라운드 결과로 돈을 벌어 준비 시간(8초)에 상점에서 무기·방탄복·수류탄류를 삽니다. 죽으면 장비를 잃습니다.
  노트북: E를 누르고 있으면 설치(3초)/해체(5초), B 상점.  모바일: 화면의 설치/해체 버튼, 상점 버튼.
- 팀 데스매치: 30킬 선취, 죽으면 3초 뒤 리스폰. 주무기는 상점에서 무료로 고르고, 리스폰할 때마다 투척 무기를 1개씩 받습니다.
- 생존전(배틀로얄): 큰 섬에 낙하산으로 내려와 바닥의 무기·방탄복·투척 무기·치료 키트를 주워 싸우고,
  줄어드는 안전 구역 안에서 마지막 1명이 될 때까지 버팁니다. 모두가 적이고, 사람이 모자라면 봇이 24명까지 채웁니다.
  · 낙하 중에는 이동 조작으로 내릴 곳을 고릅니다 (낙하 중에는 쏠 수 없음).
  · 아이템은 지나가면 저절로 줍습니다. 이미 든 무기와 바꾸려면 E(모바일: 줍기 버튼).
  · 차: 가까이 가서 E(모바일: 탑승 버튼)로 타고 내립니다. 이동 조작 앞뒤 = 가속·후진, 좌우 = 방향. 운전 중에는 쏠 수 없고, 달리는 차에 치이면 다칩니다.
  · 보급 상자: 안전 구역이 줄 때마다 다음 구역 안에 떨어집니다(지도·나침반의 주황 표시). 좋은 무기와 방탄복이 들어 있습니다.
  · 화면 위 나침반의 파란 표시가 다음 안전 구역 방향입니다.
  · 경기마다 날씨가 바뀝니다(맑은 낮·노을·안개).
  · 치료 키트: H(모바일: 치료 버튼), 2초쯤 걸리고 체력 60 회복.
  · 구역 밖에 있으면 체력이 계속 깎입니다. 미니맵의 흰 점선 원이 다음 안전 구역.
  · Tab(모바일: 점수판 버튼을 눌러 열고, [닫기]로 닫기)으로 섬 전체 지도와 순위를 봅니다.
  · 경기 중에 들어오면 관전하다가 다음 경기부터 참가합니다. 한 경기는 길어야 6분쯤.
- 방 코드로 만든 방은 처음 들어온 사람이 고른 모드와 맵으로 정해집니다.
- 캐릭터는 머리·몸통·팔 둘·다리 둘, 여섯 덩어리로 된 (모서리가 둥근) 하얀 인형이고, 저마다 그림을 그려 입힙니다.
  메뉴의 [캐릭터 그리기]에서 앞·뒤 두 장에 부드러운 붓으로 그리면 (색 20가지 + 다른 색 고르기, 붓 굵기 4단계, 채우기,
  되돌리기, 앞 → 뒤 복사, 무작위 위장) 다른 사람에게도 그 그림 그대로 보입니다.
  처음 시작할 때는 그리기 화면이 먼저 뜨고, 그림은 기기에 저장됩니다. 목의 띠가 팀 색이고, 봇은 헬멧·조끼를 갖춘 복장(색 조합 여섯 가지)입니다.
- 봇: 적이 멀면 달리고, 데스매치에서는 맵 곳곳을 순찰하며, 폭탄전 수비·설치 뒤에는 지점이 보이는 엄폐 자리에 흩어져 앉아 지킵니다.
  끼면 스스로 빠져나오고, 총소리·맞은 방향을 겨누며 다가갑니다. 난이도는 메뉴의 [봇]에서 고릅니다.
- 터치 기기를 세로로 쥐면 화면의 아래쪽 절반만 씁니다 (위쪽 절반은 비워 둠). 가로로 돌리면 화면 전체를 씁니다.
- 조작 설정 (메뉴의 [조작 설정], 게임 중에는 왼쪽 위 [조작 설정]): 설정은 기기에 저장됩니다.
  · 사격 방식: 심플(조준점이 적에 닿으면 자동 사격) / 고급(직접 사격)
  · 사격 버튼을 누르면 바로 정조준(1탭 조준 사격), 조준 버튼을 누르는 동안만 정조준, 항상 달리기
  · 조준 보정: 조준점 가까이에 보이는 적이 있으면 시점이 느려지고, 쏘거나 조준·이동 중이면 살짝 따라감 (터치 전용)
  · 감도: 기본 / 정조준 / 스코프 / 사격 중 따로 조절
  · 자이로(실험): 기기를 기울여 시점 돌리기 — 끔 / 정조준 때만 / 항상, 방향 반전
  · 터치 끊김 보정: 두 손가락을 쓸 때 터치가 잠깐 끊기는 기기용. 끊긴 뒤 0.16초 안에 다시 잡히면 이동·사격을 이어 감 (기본 꺼짐)
  · 버튼 배치 바꾸기: 버튼을 끌어 옮기고 크기(60~180%)와 투명도를 바꿈
- 메뉴의 [방 목록]에 지금 사람이 있는 방(모드·맵·인원)이 나옵니다. 누르면 그 방으로 바로 들어갑니다.
  코드로 만든 방도 목록에 보이므로, 코드를 모르는 사람도 들어올 수 있습니다.

맵
- 폭탄전·데스매치 맵 5개. 맵마다 뼈대가 되는 구조와 높낮이가 다릅니다 (서쪽이 공격, 동쪽이 수비 진영).
  · 사막 마을 (156m x 108m): 마른 수로와 그 위 돌다리, 건물 밑을 지나는 지하 통로(→ B), 오르막 끝 언덕 위의 A
  · 부두 야적장 (160m x 112m): 땅을 파 놓은 건선거 바닥의 B(위로 가로지르는 철다리, 들어와 있는 배),
    건선거에서 창고 안으로 이어지는 배수 터널, 큰 창고 A(2층 통로), 북쪽 철길 둑
  · 기차역 (192m x 88m): 승강장보다 낮은 선로 세 줄과 건널목, 선로 위를 넘는 육교, 선로 밑 지하도, 자갈 더미 언덕
  · 옛 성 (152m x 124m): 물이 찬 해자와 돌다리 네 개, 둔덕 위 본채 큰 홀(A), 성벽 위 길,
    성 밖 들판에서 해자 밑을 지나 마구간으로 나오는 비밀 지하 통로
  · 도심 교차로 (160m x 120m, 밤): 큰길 위를 넘는 고가도로, 광장 밑 지하 주차장(B, 진입로 둘), 공원 언덕, 공사장 터파기
  봇은 비탈·수로·건선거·지하 주차장·사막 마을 지하 통로·돌다리는 다니지만,
  육교·고가도로·지하도·배수 터널·성의 비밀 통로는 사람만 쓸 수 있는 길입니다.
  메뉴의 [맵]에서 고르면 그 맵만, '번갈아'면 경기가 끝날 때마다 바뀝니다. 빠른 참가 방은 항상 번갈아.
- 외딴 섬 (생존전 전용, 800m x 800m): 읍내, 등대 마을, 항구, 농장, 폐공장, 군사 기지, 비행장, 어촌, 채석장, 주유소, 폐교, 관측소, 캠프장, 옛 성터, 송신탑, 풍력 단지.
  2층 건물(여관·학교·기지 본부·관제탑)은 안쪽 계단으로 올라갈 수 있습니다.

나가기와 닫기
- 게임 중 오른쪽 위 [나가기 ✕](PC는 P 키도 가능) → "게임에서 나갈까요?" → [나가기]를 누르면 메뉴로 돌아갑니다.
- 점수판·상점·무전·무기고에는 모두 [닫기 ✕] 버튼이 있고, PC에서는 Esc 로도 닫힙니다. 점수판에는 [게임 나가기]도 있습니다.
- 연결이 끊겼을 때는 [메뉴로 나가기]가 함께 뜹니다.
- 메뉴의 [나가기 ✕]는 전체화면을 끕니다. 브라우저 탭 자체는 웹 페이지가 닫을 수 없어서, 탭을 닫거나 홈 버튼으로 나가면 됩니다.

스킨과 코드
- 메뉴의 [무기고]에서 무기 18종의 스킨을 돌려 보고 고릅니다. 무기마다 따로 고르거나 [전체 적용]으로 한 번에 바꿉니다.
- 무료 스킨 3종(기본·사막·숲 위장)은 누구나 쓸 수 있고, 나머지 10종은 코드를 등록해야 풀립니다.
- 코드로 여는 10종은 무늬만이 아니라 총의 형태가 바뀝니다(총열덮개·개머리판·총구·몸통 장식, 칼은 칼날 모양).
  카본 레드=경주차 뼈대와 날개, 맹호=갈기·발톱·송곳니 총구, 벚꽃=둥근 몸과 꽃·술, 빙결=얼음 결정,
  네온 회로=빛나는 에너지 관, 용암=바위와 뿔, 황금=깃털 날개·보석·왕관 총구, 은하=도는 궤도 고리·초승달, 오로라=프리즘 날.
  총알 궤적·총구 불꽃·착탄 불꽃 색도 스킨을 따라갑니다. 성능은 스킨과 상관없이 똑같습니다.
  등록한 코드는 그 기기(브라우저)에 저장되고, 다른 사람에게도 내 스킨이 보입니다.

사격 · 반동 · 탄착
- 반동: 총마다 정해진 무늬대로 화면이 튑니다. 연사 총은 처음 서너 발이 크게 솟고 그 뒤로 좌우로 흔들립니다. 사격을 멈추면 솟은 만큼 제자리로 돌아오고,
  손으로 눌러 준 만큼은 돌아오지 않습니다. 앉으면 반동이 줄어듭니다.
- 탄퍼짐: 정조준을 끝까지 하면 탄이 거의 조준점 그대로 갑니다. 조준하지 않고 쏘면 퍼지며, 움직이거나 뛰거나 연사할수록 더 벌어지고 조준점도 그만큼 벌어집니다.
  정조준에는 총마다 걸리는 시간이 있어서, 다 올리기 전에 쏘면 덜 정확합니다.
- 저격총: 조준경은 총을 다 올린 뒤에 뜨고, 들여다보는 동안 살짝 흔들립니다(앉으면 덜 흔들림).
  터치에서는 사격 버튼을 누르면 조준, 떼면 발사입니다. 짧게 눌렀다 떼도 조준이 끝나는 대로 발사됩니다. (조작 설정에서 끌 수 있음)
- 탄착: 맞은 곳의 재질(돌·쇠·나무·천·유리·땅·물)에 따라 탄흔, 먼지, 파편, 소리가 다릅니다. 적의 총알이 가까이 스치면 휙 소리가 납니다.

파츠 (메뉴의 [무기고] → [파츠])
- 무기마다 총구·총열·조준경·개머리판·손잡이·탄창·레이저 자리에 하나씩, 모두 5개까지 답니다. 달면 총 모양과 성능이 함께 바뀌고 성능 막대에 늘고 준 만큼이 표시됩니다.
- 개머리판 파츠는 개머리판 자체가 다른 모양으로 바뀝니다 (형태가 바뀌는 유료 스킨은 스킨 모양을 유지하고 성능만 적용).
- 파츠는 기기에 저장되고, 어느 모드에서든 그 무기를 들면 적용됩니다. 소음기를 달면 총소리가 작아지고 미니맵에 뜨지 않습니다.
- 파츠 목록과 수치: public/shared.js 의 PARTS

스킨 업그레이드
- 스킨을 낀 무기로 처치하면 그 스킨의 경험치가 오릅니다(헤드샷은 2). 레벨은 기기에 저장됩니다.
- Lv.2 (5) 궤적 색 · Lv.3 (15) 총구 불꽃·탄착 색 · Lv.4 (35) 처치 효과 · Lv.5 (70) 각성(총에 빛줄기가 흐름). 기준 처치 수: public/shared.js 의 SKIN_LV
- '기본' 스킨에는 레벨이 없습니다.

봇
- 메뉴의 [봇]에서 난이도를 고릅니다(쉬움·보통·어려움·매우 어려움). 방 코드를 처음 만든 사람의 선택이 그 방에 적용되고, 빠른 참가 방은 '보통'입니다.
- 봇은 시야각 안에서만 적을 발견하고, 총소리가 난 곳을 살피러 가고, 맞으면 쏜 쪽을 돌아봅니다. 탄창을 다 쓰면 장전하고,
  체력이 낮거나 장전 중일 때는 엄폐물 뒤로 숨습니다. 무기에 따라 거리를 벌리거나 좁히고, 팀전에서는 본 적의 위치를 팀원에게 알립니다.

그 밖의 기능
- 죽은 사람의 주무기는 바닥에 떨어지고, 주무기가 없는 사람이 밟으면 줍습니다(폭탄전).
- 무전: 화면 위 [무전] 또는 Z(A 지점으로) X(B 지점으로) V(적 발견) H(도와줘) — 같은 팀에게만 보입니다.
- 팀 바꾸기: 상점 아래 [팀 바꾸기] (폭탄전은 다음 라운드부터 적용).
- 죽은 뒤 화면을 누르거나 Space/클릭으로 다른 사람 관전.
- 메뉴에서 조준선 색과 화질을 고를 수 있습니다. 느린 기기에서는 화질 '낮음'(그림자 끔)을 권합니다.

파일 구성
- server.js            게임 서버 (방, 라운드, 돈, 생존전, 봇, 피격·폭발 판정)
- public/maps.js       맵 6개(경기장 5 + 섬)의 구조·지형·아이템 자리 (서버와 화면이 함께 씀)
- public/shared.js     무기 성능·가격, 파츠, 스킨 레벨, 충돌·사격 판정 (서버와 화면이 함께 씀)
- public/paint.js      그림을 그리는 캐릭터 (몸 모양, 그리기 화면, 그림 주고받기)
- public/world.js      맵 그래픽 (질감, 지형, 바다, 나무, 그림자, 하늘, 소품, 표지판)
- public/guns.js       무기 모델 18종, 파츠 모양, 스킨 무늬, 스킨별 형태(KITS) (칼, 보조무기 5, 기관단총 2, 샷건 2, 소총 4, 저격총 2, 기관총 2)
- public/game.js       화면·조작·효과·소리
- public/index.html    메뉴와 화면 구성

게임 규칙을 바꾸고 싶다면
- server.js 맨 위: 라운드 수(ROUNDS_WIN), 라운드 시간(ROUND_MS), 준비 시간(FREEZE_MS), 폭탄 시간(BOMB_MS), 데스매치 목표 킬(KILL_LIMIT), 팀 인원(TEAM_MIN/TEAM_MAX)
- server.js 의 BR = { … }: 생존전 전체 인원(total), 시작 전 대기(wait), 구역이 줄어드는 단계와 피해(zones), 치료량(heal), 무기가 나올 비중(wWeight), 보급 상자 무기(airLoot)
- server.js 의 LV = [ … ]: 난이도별 봇의 반응 시간·조준 오차·피해 배율
- public/shared.js: 무기 성능과 가격(WEAPONS), 파츠(PARTS), 스킨 레벨(SKIN_LV), 투척 무기(NADES), 돈(ECON), 스킨 목록(SKINS)
- server.js 의 SKIN_CODES: 스킨 코드
- public/maps.js: 맵 구조(B(...) 줄들), 폭탄 지점, 섬의 건물·나무·아이템 자리
